## 繁體中文

### 關於這個倉庫

這個倉庫用來整理及放置我目前實際使用的 Agent Skills，並依適用及實際使用的環境區分為 ChatGPT Work 與 Codex。

收錄內容可能包含：

* 我完全自行製作的 Skills
* 我以其他 Skills 為基礎，依照我的實際需求改良的 Skills
* 正在使用並且授權允許重新散布的第三方 Skills

只有來源與授權已確認、且目前仍在使用的內容，才會加入這個公開倉庫。

### 收錄原則

* 依主要使用環境區分 ChatGPT Work 與 Codex Skills。
* 每個 Skill 都會在對應資料夾的 README 中，說明我將它用在哪些情境、如何安裝，以及我的實際使用方式。
* 第三方內容會保留原作者、來源及授權資訊。
* 修改自其他專案的內容會清楚記錄主要變更。
* 公開檔案不包含憑證、私人路徑或個人對話紀錄。

### 安裝與使用

這個專案中的每個 Skill 都會在各自的資料夾中，提供我的安裝方式、實際使用方式及相關說明。請先閱讀該 Skill 的文件，確認適用環境及安裝方式。

### 來源與授權

這個倉庫中的 Skills 可能使用不同授權。請以各 Skill 資料夾內的來源及授權文件為準，不要假設整個倉庫的所有內容都使用同一種授權。

### 免責聲明

這是獨立維護的社群倉庫，不是 OpenAI 官方專案，也不代表 OpenAI 的認可或背書。

## English

### About This Repository

This repository is used to organize and store the Agent Skills I currently use. They are categorized as ChatGPT Work or Codex Skills according to the environments they support and the environments in which I actually use them.

The repository may include:

* Skills created entirely by me
* Skills adapted from other Skills to meet my actual needs
* Third-party Skills that I currently use and whose licenses permit redistribution

Only content whose source and license have been verified and that I still actively use will be added to this public repository.

### Repository Principles

* Skills are categorized by the main environment in which I use them: ChatGPT Work or Codex.
* Each Skill’s README will explain what I use it for, how I install it, and how I use it in practice.
* Third-party content will retain its original author, source, and license information.
* Significant changes made to content adapted from other projects will be clearly documented.
* Public files will not contain credentials, private paths, or personal conversation records.

### Installation and Usage

Each Skill in this repository will include documentation in its own directory explaining how I install it, how I use it in practice, and any related instructions. Please read the Skill’s documentation first to confirm its supported environment and installation method.

### Sources and Licenses

Skills in this repository may use different licenses. Refer to the source and license information inside each Skill directory. Do not assume that every file in this repository is covered by the same license.

This is an independently maintained community repository. It is not an official OpenAI project and is not affiliated with or endorsed by OpenAI.
