# ChatGPT Work Skills

[← 返回倉庫首頁｜Back to Repository Home](../README.md)

## 繁體中文

這個資料夾收錄我目前實際在 ChatGPT Work 中使用的 Agent Skills。

每個 Skill 都會放在獨立的子資料夾中，並提供：

* Skill 的用途
* 我的安裝方式
* 我的實際使用方式
* 原始來源與授權資訊
* 修改內容與原版差異（如果有）

第三方 Skill 必須先確認來源與授權允許公開及重新散布，才會加入這個資料夾。

## English

This directory contains the Agent Skills I currently use in ChatGPT Work.

Each Skill will be placed in its own subdirectory and will provide:

* The purpose of the Skill
* How I install it
* How I use it in practice
* Its original source and license information
* Changes made and differences from the original version, if any

A third-party Skill will only be added to this directory after confirming that its source and license permit public publication and redistribution.
